1. **Schema版本治理**：旧与当前都是 okx-research-plan-v1，但新增 signal_state/signal_timing。旧数据当前能解析；应后续明确兼容策略、Schema摘要或次版本，不改历史产物。
2. **分阶段文档索引**：早期“三公开路径”“未实现回测”是历史阶段描述。当前总表改由本验收目录提供；不把历史交付记录当最新手册。
3. **报告生成时间无时区**：Generated 是本地时间字符串，cutoff/latest_close 是UTC。后续可统一展示UTC与本地时区，但不能重写旧报告时间。
4. **冻结命令的使用边界**：旧 D.4.1 --execute/--analyze 在当前增量下可能被代码指纹拒绝。手册必须区分读取旧记录与新实验，不能为了操作便利关闭保护。
5. **测试环境与可选依赖**：无pip不是当前运行失败；Bedrock可选包缺失产生skip，不宣称该提供商已验证。直接依赖满足不等于全部传递依赖已完成求解或跨平台发行验证。
6. **质量语义**：data_quality=VALID、allow_new_risk、plan_valid、ENTRY_ELIGIBLE、execution_enabled 属于不同层。下游只读报告消费者也必须保留此区分。
